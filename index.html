Schnelle Antworten

Die wichtigsten Fragen

Claude Code ist ein KI-Assistent, der direkt in deinem Terminal läuft. Er kann Code schreiben, Dateien bearbeiten, Git-Commits erstellen, mit externen Tools wie Figma oder Asana interagieren und komplexe Workflows automatisieren. Über sogenannte Skills und MCP-Integrationen wird Claude Code zu einer vollständigen Content Engine für Ad-Erstellung, Design-Automatisierung und mehr.

Aktuell sind 7 MCP-Server konfiguriert: Asana (Projektmanagement), Figma (Design-Automatisierung), Google Drive (Dateiverwaltung, Sheets, Docs), Higgsfield (KI-Bild- & Videogenerierung), Close CRM (Sales & Lead-Management), Gmail (E-Mail-Automatisierung) und Google Calendar (Terminplanung). Jeder MCP erweitert Claude Code um spezifische Fähigkeiten.

Die Kosten variieren je nach Modell: Nano Banana 2 (Gemini Flash) kostet ca. $0.02 pro Bild, Seedream 4.5 und Flux Pro jeweils $0.04, Ideogram V2 $0.08 und Nano Banana Pro (Gemini Pro) ca. $0.14. Über Higgsfield kostet GPT Image 2 etwa 4 Credits pro Bild. Claude Code zeigt dir immer einen Kostenvoranschlag bevor generiert wird.

Tippe einfach den Skill-Namen mit einem Slash ein, z.B. /ad-session, /d4y oder /logo. Claude Code erkennt den Befehl und führt den entsprechenden Workflow automatisch aus. Jeder Skill hat eine eigene Dokumentation in der SKILL.md Datei, die beschreibt was er macht und welche Eingaben er braucht.

Deine zentrale Anlaufstelle für Claude Code Wissen, MCP-Integrationen und Workflow-Dokumentation.
