Multi-Agent Workflows: AI-Teams orchestrieren

Fortgeschritten 📖 8 Min. Lesezeit Aktualisiert: Juni 2026
Video: Multi-Agent Setup in der Praxis

Was sind Multi-Agent Workflows?

Statt einem einzelnen Claude Code für alles, kannst du mehrere Instanzen gleichzeitig laufen lassen — jede mit einer spezialisierten Rolle. Das ist wie ein Team aus AI-Spezialisten, die parallel arbeiten.

Typische Agent-Rollen

Agent Rolle Aufgabe
Designer Creative Direction Layout, Farbschema, Bildauswahl
Frontend Dev Implementierung HTML/CSS/JS Code schreiben
CTO / Reviewer Qualitätssicherung Code Review, Architektur-Entscheidungen
QA Testing Testen, Bugs finden, Edge Cases

Setup mit Tmux

Der einfachste Weg mehrere Claude-Instanzen parallel zu nutzen ist Tmux (Terminal Multiplexer). Du kannst dein Terminal in mehrere Panels aufteilen, in jedem eine Claude-Instanz starten.

# Tmux starten
tmux new -s agents

# Panel horizontal teilen
Ctrl+B, dann %

# Panel vertikal teilen
Ctrl+B, dann "

# Zwischen Panels wechseln
Ctrl+B, dann Pfeiltaste

Wann lohnt sich Multi-Agent?

Faustregel: Multi-Agent lohnt sich wenn du einen Workflow hast, bei dem verschiedene Perspektiven einen Mehrwert bringen, oder wenn Aufgaben parallel stattfinden können. Für einfache, lineare Tasks ist ein einzelner Agent effizienter.

Gut geeignet:

  • Website-Entwicklung (Design + Code + QA parallel)
  • Code Review (unabhängige Reviews aus verschiedenen Perspektiven)
  • Content-Erstellung in großem Maßstab (mehrere Artikel gleichzeitig)
  • Research + Implementation parallel

Weniger sinnvoll:

  • Einfache Dateibearbeitungen
  • Sequenzielle Workflows (ein Schritt hängt vom vorherigen ab)
  • Aufgaben die weniger als 5 Minuten dauern

Claude Code Subagents

Innerhalb einer Claude Code Session kannst du auch Subagents spawnen. Das sind spezialisierte Agents die im Hintergrund arbeiten und ihre Ergebnisse zurückliefern:

  • Explore Agent: Schnelle Code-Suche und Dateien finden
  • Plan Agent: Implementierungspläne erstellen
  • Code Review Agent: Änderungen prüfen
  • General Purpose: Komplexe Recherche-Aufgaben

Workflows (Multi-Agent Scripts)

Für deterministische Multi-Agent Workflows gibt es Workflow-Scripts. Diese orchestrieren mehrere Agents mit klarer Logik:

// Beispiel: Review-Workflow
// 1. Parallel: 3 Reviewer prüfen den Code
// 2. Ergebnisse zusammenführen
// 3. Verifizierung der Findings
phase('Review')
const findings = await parallel([
  () => agent('Prüfe auf Bugs'),
  () => agent('Prüfe Performance'),
  () => agent('Prüfe Security')
])
phase('Verify')
// ... Adversarial Verification

Das ist das "Endgame" — wer Multi-Agent-Workflows beherrscht, verzehnfacht seine Produktivität.
