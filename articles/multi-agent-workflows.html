Multi-Agent Workflows: AI-Teams orchestrieren

Fortgeschritten 📖 8 Min. Lesezeit Aktualisiert: Juni 2026

Was sind Multi-Agent Workflows?

Statt einer einzelnen Claude Code Instanz, die alles alleine macht, lässt du mehrere spezialisierte Instanzen parallel arbeiten. Jede Instanz hat eine klar definierte Rolle — wie ein echtes Team, nur dass jedes Mitglied eine KI ist.

Das Ergebnis: schnellere Durchläufe, bessere Qualität durch Spezialisierung und eingebaute Qualitätskontrolle, weil ein Agent den Output eines anderen prüft.

Typische Agenten-Rollen

RolleAufgabeBeispiel-Anweisung
DesignerCreative Direction"Erstelle 3 Designkonzepte für die Landingpage"
Frontend DevImplementation"Setze das Design in HTML/CSS um"
CTO / ReviewerQuality Assurance"Prüfe den Code auf Best Practices und Performance"
QATesting"Teste alle Links, Responsiveness und Accessibility"

Setup mit Tmux

Tmux (Terminal Multiplexer) ist das ideale Werkzeug für Multi-Agent Workflows. Du kannst mehrere Terminal-Panes in einem Fenster öffnen und in jedem eine eigene Claude Code Instanz starten.

Tmux-Session starten

Erstelle eine neue benannte Session für dein Agenten-Team:

tmux new -s agents

Panes aufteilen

Teile das Fenster horizontal und vertikal auf, sodass du mehrere Bereiche hast:

# Vertikal teilen
Ctrl+B %

# Horizontal teilen
Ctrl+B "

# Zwischen Panes wechseln
Ctrl+B Pfeiltaste

Claude Code in jedem Pane starten

Starte in jedem Pane eine Claude Code Instanz mit einer spezifischen Rolle. Gib jeder Instanz ihren Auftrag als erste Nachricht.

Tipp: Gib jedem Agenten in der ersten Nachricht eine klare Rollenanweisung: "Du bist der Frontend-Entwickler in diesem Team. Deine Aufgabe ist ausschließlich die Implementation in HTML/CSS."

Wann ist Multi-Agent sinnvoll?

Gut geeignet

  • Website-Entwicklung: Designer entwirft, Developer setzt um, Reviewer prüft — parallel
  • Code Review: Ein Agent schreibt Code, ein anderer reviewt ihn in Echtzeit
  • Content at Scale: Mehrere Agenten erstellen gleichzeitig verschiedene Content-Pieces
  • Research + Implementation: Ein Agent recherchiert, ein anderer setzt die Ergebnisse direkt um

Nicht geeignet

  • Einfache Edits: Eine einzelne Datei anpassen braucht kein Team
  • Streng sequentielle Workflows: Wenn Schritt B zwingend auf Schritt A warten muss
  • Tasks unter 5 Minuten: Der Setup-Overhead lohnt sich nicht

Claude Code Subagents

Neben dem manuellen Tmux-Setup bietet Claude Code auch eingebaute Subagents, die automatisch im Hintergrund arbeiten:

SubagentFunktionWann eingesetzt
Explore AgentDurchsucht die Codebase nach relevanten Dateien und ZusammenhängenBei komplexen Fragen über große Projekte
Plan AgentErstellt einen detaillierten Umsetzungsplan bevor Code geschrieben wirdBei umfangreichen Änderungen
Code Review AgentPrüft Diffs auf Bugs, Performance und Best PracticesVor Commits und PRs
General PurposeFührt beliebige Aufgaben parallel ausFür parallelisierbare Teilaufgaben

Subagents werden automatisch gestartet, wenn Claude Code erkennt, dass eine Aufgabe von Parallelisierung profitiert. Du kannst sie aber auch explizit anfordern.

Workflows (Multi-Agent Scripts)

Für wiederkehrende Multi-Agent Setups kannst du Workflows als Scripts definieren. Die drei Kern-Bausteine sind:

BausteinZweck
phase()Definiert eine benannte Phase im Workflow
parallel()Führt mehrere Agenten gleichzeitig aus
agent()Startet einen einzelnen Agenten mit einer spezifischen Aufgabe
 
# Beispiel: Website-Erstellung als Multi-Agent Workflow

phase("Design")
  agent("designer", "Erstelle 3 Layouts für die Homepage")

phase("Implementation")
  parallel(
    agent("frontend", "Setze Layout 1 in HTML/CSS um"),
    agent("content", "Schreibe alle Texte für die Homepage")
  )

phase("Review")
  parallel(
    agent("reviewer", "Prüfe Code auf Qualität und Performance"),
    agent("qa", "Teste Responsiveness auf allen Breakpoints")
  )

Hinweis: Multi-Agent Workflows funktionieren am besten, wenn jeder Agent seinen eigenen Bereich hat und es klare Übergabepunkte gibt. Wenn zwei Agenten dieselbe Datei gleichzeitig bearbeiten, kommt es zu Konflikten.
