Alle Skills im Überblick

Referenz 📖 15 Min. Lesezeit Aktualisiert: Juni 2026

Was sind Skills?

Skills sind vorgefertigte Workflows, die Claude Code mit einem Slash-Befehl aktiviert. Jeder Skill hat eine eigene SKILL.md Datei mit Dokumentation, Trigger-Wörtern und Referenz-Dateien. Sie liegen im Verzeichnis .claude/skills/.

Wichtig: Diese Skills stehen dir nur zur Verfügung, wenn du das Heartbeat Content Engine Repo von GitHub geklont und in Claude Code geöffnet hast. Ohne die GitHub-Anbindung sind die Skills nicht vorhanden. Diese Übersicht dient auch als Inspiration, welche Skills man selbst erstellen kann. Falls ein Skill bei dir fehlt oder nicht funktioniert, frag einfach bei Lea nach.

Nutzung: Tippe /skillname in Claude Code ein, z.B. /ad-session. Claude Code erkennt den Skill und führt den definierten Workflow automatisch aus.

Ad-Erstellung & Copywriting

/ad-session

Generiert komplette Heartbeat AD Copy Dokumente für Meta & LinkedIn. 13 Pflichtfelder, 5 Freebie-Titel, 7 Video-Hooks, 6 Bild-ADs. Export als DOCX.

/ad-session-mini

Kompakte Version der Ad-Session für schnellere Ergebnisse mit weniger Varianten.

/ad-kunden

Verwaltet gespeicherte Kundenprofile für wiederkehrende AD Copy & Creative Jobs. Kundeninfos werden automatisch wiederverwendet.

/creative-engine

Orchestriert KI-Bildgenerierung für Ad-Creatives aus Referenz-Templates. Airtable als Review-Hub, Status-Tracking von Pending bis Approved.

Weitere Ad-Skills

/story-ad

Konvertiert 1:1 Meta Ads (1080×1080) ins 9:16 Story-Format. Automatische Layout-Anpassung ohne CTA-Button.

/recruiting-ad

Generiert 3 Recruiting-Creatives im Homeoffice-Format (4:5). Bis zu 2 Jobtitel, keine Region-Bubble.

Hinweis: Zusätzlich gibt es kundenspezifische Ad-Skills, die auf bestimmte Marken-CIs zugeschnitten sind. Diese werden individuell im Repo konfiguriert und sind hier nicht gelistet.

Wie nutze ich einen Skill?

Skill aufrufen

Tippe den Slash-Befehl ein: /skillname. Claude Code lädt die Skill-Dokumentation und startet den Workflow.

Inputs liefern

Je nach Skill wirst du nach bestimmten Informationen gefragt: Kundenname, Produkt, Zielgruppe, CI-Farben, etc.

Kosten bestätigen

Bei Skills die APIs nutzen (Bildgenerierung, etc.) siehst du einen Kostenvoranschlag und musst bestätigen.

Ergebnis prüfen

Die Ergebnisse werden im passenden Output-Ordner gespeichert. Bei vielen Skills öffnet sich der Ordner automatisch im Finder.
