Claude Code im Terminal einrichten

Beginner 📖 12 Min. Lesezeit Aktualisiert: Juni 2026

Was wird installiert?

Claude Code ist Anthropics KI-Assistent für das Terminal. Er kann Dateien lesen und schreiben, Bilder generieren, im Web suchen und mit verschiedenen Diensten interagieren. Für die Einrichtung werden drei Dinge installiert:

  • Homebrew — Paketmanager für macOS (installiert alles Weitere)
  • Node.js — JavaScript-Runtime (wird von Claude Code benötigt)
  • Claude Code — Der KI-Assistent selbst

Voraussetzungen

  • MacBook mit macOS 15 (Sequoia) oder neuer
  • Internetzugang
  • Admin-Rechte (eigenes Benutzerkonto)
  • Anthropic-Account (claude.ai) mit aktivem Abo (Max, Pro oder Team)

Alle Schritte werden im selben Terminal-Fenster durchgeführt. Du musst zwischendurch KEIN neues Terminal öffnen. Einfach einen Befehl nach dem anderen eingeben.

Terminal öffnen

Finder → Programme → Dienstprogramme → Terminal. Dieses Fenster bleibt während der gesamten Einrichtung offen. Alle Code-Blöcke in dieser Anleitung sind Befehle, die du dort einfügst.

1. Homebrew installieren

Diesen Befehl ins Terminal kopieren und Enter drücken:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Was jetzt passiert:

  1. Das Skript fragt nach dem Mac-Passwort. Eingeben (es wird nichts angezeigt!) und Enter drücken.
  2. Es erscheint eine Liste, was installiert wird. Enter drücken zum Bestätigen.
  3. Die Installation läuft. Das kann 2–10 Minuten dauern.

Falls eine Meldung erscheint, dass Xcode Command Line Tools installiert werden: Das ist normal! Einfach warten, bis es fertig ist. Kann bis zu 10 Minuten dauern.

1.1 Homebrew aktivieren

Wenn die Installation fertig ist, erscheint wieder der blinkende Cursor. Jetzt diese zwei Befehle nacheinander eingeben (einzeln kopieren, Enter, nächsten kopieren, Enter):

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile

Dieser Befehl gibt keine Ausgabe. Das ist normal. Weiter mit:

eval "$(/opt/homebrew/bin/brew shellenv)"

Auch hier keine Ausgabe. Normal.

1.2 Testen, ob Homebrew funktioniert

brew --version

Wenn eine Versionsnummer erscheint (z.B. "Homebrew 6.0.1"), hat es funktioniert. Weiter mit Schritt 2.

2. Node.js installieren

Direkt im gleichen Terminal eingeben:

brew install node

Homebrew lädt und installiert Node.js. Dauert ca. 1–2 Minuten. Warten, bis der Cursor wieder blinkt.

2.1 Testen

node --version

Wenn eine Versionsnummer erscheint (z.B. "v25.9.0"), hat es funktioniert. Weiter mit Schritt 3.

3. Claude Code installieren

Direkt im gleichen Terminal eingeben:

npm install -g @anthropic-ai/claude-code

npm (der Node-Paketmanager) lädt Claude Code herunter. Dauert ca. 30 Sekunden.

3.1 Testen

claude --version

Erwartete Ausgabe: eine Versionsnummer wie "2.1.177 (Claude Code)". Weiter mit Schritt 4.

4. Einstellungen konfigurieren

Bevor Claude Code das erste Mal richtig gestartet wird, legen wir die Einstellungen an. So antwortet Claude direkt auf Deutsch und nutzt das beste Modell.

Den folgenden Block KOMPLETT markieren und als Ganzes ins Terminal einfügen (nicht Zeile für Zeile!):

mkdir -p ~/.claude && cat > ~/.claude/settings.json << 'EOF'
{
  "enableAllProjectMcpServers": true,
  "language": "Deutsch",
  "model": "claude-opus-4-6",
  "voiceEnabled": true
}
EOF

Wichtig: Den gesamten Block auf einmal kopieren und einfügen! Von "mkdir" bis "EOF" — alles markieren, kopieren, einfügen, Enter. Es erscheint keine Ausgabe. Die Datei wurde im Hintergrund erstellt.

4.1 Prüfen, ob es geklappt hat

cat ~/.claude/settings.json

Hier sollte der JSON-Inhalt erscheinen, den du gerade eingefügt hast.

Was diese Einstellungen machen:

  • enableAllProjectMcpServers: Erlaubt Verbindungen zu externen Diensten
  • language: Claude antwortet auf Deutsch
  • model: Nutzt das stärkste Modell (Opus)
  • voiceEnabled: Spracheingabe aktiviert

5. Claude Code starten & einloggen

Jetzt Claude Code zum ersten Mal starten:

claude

Was jetzt passiert:

  1. Claude Code fragt nach dem Login. Ein Browser-Fenster öffnet sich automatisch.
  2. Im Browser mit dem Anthropic-Account (claude.ai) einloggen.
  3. Die Verbindung bestätigen ("Authorize" klicken).
  4. Zurück zum Terminal wechseln. Claude Code ist jetzt bereit.

Achtung: Der Anthropic-Account muss ein aktives Abo haben (Max, Pro oder Team). Ohne Abo erscheint eine Fehlermeldung.

Claude Code ist jetzt aktiv. Du siehst eine Eingabezeile und kannst direkt lostippen. Zum Beenden: Ctrl+C drücken oder /exit eingeben.

6. MCP-Dienste verbinden

MCP-Dienste erweitern Claude um externe Fähigkeiten wie Bildgenerierung. Ein Befehl im Terminal reicht — die Anmeldung passiert automatisch.

Wichtig: Falls Claude Code noch läuft, zuerst mit Ctrl+C oder /exit beenden. Die folgenden Befehle werden in der normalen Terminal-Shell eingegeben, nicht in Claude Code.

6.1 Higgsfield verbinden (Bildgenerierung)

claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp

Beim nächsten Start von Claude Code und der ersten Bild-Anfrage öffnet sich automatisch ein Browser-Fenster zur Higgsfield-Anmeldung. Einmal bestätigen — danach funktioniert es dauerhaft.

6.2 Prüfen

claude mcp list

In der Liste sollte higgsfield mit der URL https://mcp.higgsfield.ai/mcp erscheinen.

6.3 Weitere Dienste (optional)

Andere MCP-Dienste werden genauso verbunden — immer das gleiche Muster:

claude mcp add --transport http --scope user [name] [url]

Beispiele:

claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp
claude mcp add --transport http --scope user slack https://mcp.slack.com/mcp

Beim ersten Nutzen öffnet sich jeweils automatisch die Anmeldung im Browser.

7. Erster Test

Falls Claude Code noch läuft, kannst du direkt lostippen. Falls nicht, starte es erneut:

claude

7.1 Deutsch testen

Tippe in Claude Code:

Hallo! Antworte mir bitte auf Deutsch.

Claude sollte auf Deutsch antworten.

7.2 Bildgenerierung testen (wenn Higgsfield verbunden)

Tippe in Claude Code:

Generiere mir ein Bild von einem Sonnenuntergang am Meer.

Claude nutzt Higgsfield und erstellt ein Bild. Beim ersten Mal öffnet sich ein Browser-Fenster zur Higgsfield-Anmeldung — Zugriff bestätigen, dann wird das Bild generiert.

7.3 Nützliche Befehle

Befehl Was er macht
Ctrl+C Claude Code beenden
/exit Claude Code beenden (Alternative)
/help Übersicht aller verfügbaren Befehle
/clear Konversation löschen und neu starten
claude Im Terminal eingeben, um Claude Code erneut zu starten

Checkliste

Alles eingerichtet? Prüfe diese Punkte:

  • Homebrew: brew --version zeigt eine Versionsnummer
  • Node.js: node --version zeigt eine Versionsnummer
  • Claude Code: claude --version zeigt eine Versionsnummer
  • Einstellungen: cat ~/.claude/settings.json zeigt die JSON-Konfiguration
  • Login: claude startet ohne Fehlermeldung
  • Deutsch: Claude antwortet auf Deutsch
  • Higgsfield (optional): claude mcp list zeigt den Eintrag

Was kommt als Nächstes?

Claude Code läuft und ist einsatzbereit. Als Nächstes solltest du die MCP-Integrationen kennenlernen, die deine Möglichkeiten massiv erweitern — oder direkt deinen ersten Skill ausprobieren.

Die CLAUDE.md Datei

Wenn du in ein Projektverzeichnis navigierst und dort claude startest, sucht Claude Code automatisch nach einer CLAUDE.md Datei. Diese definiert die Rolle, Regeln und verfügbaren Tools für das Projekt. Du musst sie nicht manuell bearbeiten — Claude Code liest sie automatisch beim Start.

Memory-System

Claude Code hat ein persistentes Gedächtnis. Wenn du sagst "Merk dir das", speichert er die Information ab. Beim nächsten Start hat er automatisch Zugriff auf alles Gespeicherte. Das Memory unterscheidet zwischen:

  • User-Memories: Infos über dich (Rolle, Vorlieben)
  • Feedback-Memories: Korrekturen und bestätigte Vorgehensweisen
  • Project-Memories: Laufende Projekte und Kunden-Infos
  • Reference-Memories: Verweise auf externe Systeme
