Claude Code im Terminal einrichten

Beginner 📖 10 Min. Lesezeit Aktualisiert: August 2026

Was ist Claude Code?

Claude Code ist Anthropics KI-Assistent für das Terminal. Er kann Dateien lesen und schreiben, Bilder und Videos generieren, im Web recherchieren und über MCP-Server mit externen Diensten (Figma, Google Drive, Slack, Higgsfield …) arbeiten. Diese Anleitung bringt dich in wenigen Minuten von null auf einen fertig eingerichteten Claude Code.

Neu seit 2026: Claude Code hat einen eigenen nativen Installer. Der braucht weder Homebrew noch Node.js und hält sich selbst automatisch aktuell. Das ist der schnellste und stabilste Weg — nimm ihn, wenn du keinen speziellen Grund für etwas anderes hast.

Voraussetzungen

  • Mac mit macOS 15 (Sequoia) oder neuer
  • Internetzugang
  • Eigenes Benutzerkonto (Admin-Rechte)
  • Anthropic-Account (claude.ai) mit aktivem Abo (Max, Pro oder Team)

Terminal öffnen

Finder → Programme → Dienstprogramme → Terminal. Alle Code-Blöcke in dieser Anleitung sind Befehle, die du dort einfügst — einen nach dem anderen, jeweils mit Enter.

1. Claude Code installieren (empfohlener Weg)

Diesen einen Befehl ins Terminal kopieren und Enter drücken:

curl -fsSL https://claude.ai/install.sh | bash

Der Installer lädt eine fertige Programmdatei herunter und legt sie unter ~/.local/bin/claude ab. Das dauert nur ein paar Sekunden. Homebrew, Node.js oder npm werden dabei nicht gebraucht.

Wichtig: Nach der Installation einmal ein neues Terminal-Fenster öffnen (oder das aktuelle schließen und neu öffnen). Erst dann kennt das Terminal den Befehl claude.

1.1 Testen, ob es funktioniert hat

claude --version

Erwartete Ausgabe: eine Versionsnummer wie 2.1.204 (Claude Code). Wenn das erscheint, ist die Installation fertig — weiter mit Schritt 2.

Falls claude: command not found erscheint: Das Terminal kennt den neuen Befehl noch nicht. Neues Terminal-Fenster öffnen und nochmal probieren. Hilft das nicht, diesen Befehl ausführen: echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zprofile — dann Terminal neu starten.

1.2 Diagnose bei Problemen

Claude Code bringt ein eingebautes Diagnose-Tool mit. Wenn irgendetwas hakt, gibt dieser Befehl eine klare Übersicht (Installation, Version, Login, MCP-Server):

claude doctor

2. Einstellungen konfigurieren

Bevor du Claude Code das erste Mal startest, legen wir die Grundeinstellungen an — so antwortet Claude direkt auf Deutsch und nutzt das stärkste Modell.

Den folgenden Block KOMPLETT markieren (von mkdir bis EOF) und als Ganzes ins Terminal einfügen — nicht Zeile für Zeile:

mkdir -p ~/.claude && cat > ~/.claude/settings.json << 'EOF'
{
  "model": "sonnet",
  "language": "Deutsch",
  "enableAllProjectMcpServers": true,
  "theme": "dark",
  "voiceEnabled": true
}
EOF

Hinweis: Es erscheint keine Ausgabe — die Datei wurde im Hintergrund erstellt. Falls du schon eine settings.json mit anderen Einträgen hast, überschreibt dieser Befehl sie. In dem Fall die Werte lieber von Hand ergänzen.

2.1 Prüfen, ob es geklappt hat

cat ~/.claude/settings.json

Hier sollte der JSON-Inhalt erscheinen, den du gerade eingefügt hast.

Was diese Einstellungen machen:

  • model: "sonnet" ist der Standard und wählt immer automatisch das aktuelle Sonnet-Modell (derzeit Sonnet 5) — die beste Balance aus Tempo und Qualität für den Alltag. Weil es ein Alias ist, bleibt die Einstellung auch nach Updates korrekt; du musst nie eine Versionsnummer nachpflegen.
  • language: Claude antwortet auf Deutsch.
  • enableAllProjectMcpServers: Erlaubt Verbindungen zu allen im Projekt hinterlegten MCP-Servern.
  • theme: Dunkles Terminal-Design.
  • voiceEnabled: Spracheingabe aktiviert.

Profi-Tipp: Für besonders knifflige Aufgaben kannst du jederzeit mitten in der Sitzung mit /model auf Opus (das stärkste Modell) wechseln. Wer dauerhaft mehr Gedächtnis pro Sitzung braucht, trägt "sonnet[1m]" ein — das schaltet das große 1-Million-Token-Kontextfenster frei.

3. Claude Code starten & einloggen

Jetzt Claude Code zum ersten Mal starten:

claude

Was jetzt passiert:

  1. Claude Code fragt nach dem Login — ein Browser-Fenster öffnet sich automatisch.
  2. Im Browser mit dem Anthropic-Account (claude.ai) einloggen.
  3. Die Verbindung bestätigen („Authorize“ klicken).
  4. Zurück zum Terminal wechseln — Claude Code ist jetzt bereit.

Achtung: Der Anthropic-Account muss ein aktives Abo haben (Max, Pro oder Team). Ohne Abo erscheint eine Fehlermeldung.

Claude Code ist jetzt aktiv. Du siehst eine Eingabezeile und kannst direkt lostippen. Zum Beenden: /exit eingeben oder zweimal Ctrl+C drücken.

4. MCP-Dienste verbinden

MCP-Server erweitern Claude um externe Fähigkeiten — z. B. Bildgenerierung über Higgsfield. Ein Befehl im Terminal reicht, die Anmeldung passiert danach automatisch im Browser.

Wichtig: Diese Befehle in der normalen Terminal-Shell eingeben, nicht innerhalb von Claude Code. Falls Claude Code noch läuft, vorher mit /exit beenden.

4.1 Higgsfield verbinden (Bildgenerierung)

claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp

Beim nächsten Start von Claude Code und der ersten Bild-Anfrage öffnet sich automatisch ein Browser-Fenster zur Higgsfield-Anmeldung. Einmal bestätigen — danach funktioniert es dauerhaft.

4.2 Prüfen

claude mcp list

In der Liste sollte higgsfield mit der URL https://mcp.higgsfield.ai/mcp erscheinen.

4.3 Weitere Dienste (optional)

Andere MCP-Server werden nach dem gleichen Muster verbunden:

claude mcp add --transport http --scope user [name] [url]

Beim ersten Nutzen öffnet sich jeweils automatisch die Anmeldung im Browser. Eine Übersicht aller empfohlenen Server findest du im Artikel MCP-Integrationen.

5. Erster Test

Claude Code starten (falls es nicht mehr läuft):

claude

5.1 Deutsch testen

Tippe in Claude Code:

Hallo! Fasse mir in zwei Sätzen zusammen, was du alles kannst.

Claude sollte auf Deutsch antworten.

5.2 Bildgenerierung testen (wenn Higgsfield verbunden)

Tippe in Claude Code:

Generiere mir ein Bild von einem Sonnenuntergang am Meer.

Claude nutzt Higgsfield und erstellt ein Bild. Beim ersten Mal öffnet sich ein Browser-Fenster zur Higgsfield-Anmeldung — Zugriff bestätigen, dann wird das Bild generiert.

5.3 Nützliche Befehle

Befehl Was er macht
claude Claude Code im Terminal starten
/exit Claude Code beenden (oder zweimal Ctrl+C)
/help Übersicht aller verfügbaren Befehle
/clear Konversation löschen und frisch starten
/model Modell mitten in der Sitzung wechseln
claude doctor Diagnose bei Problemen (im Terminal, nicht in Claude)
claude update Manuell auf die neueste Version aktualisieren

Alternative: Installation über Homebrew + Node.js

Du brauchst diesen Weg nur, wenn du bewusst über npm/Node arbeiten willst. Für die normale Einrichtung ist der native Installer aus Schritt 1 einfacher und stabiler. Falls du diesen Weg trotzdem gehst:

A. Homebrew installieren

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Das Skript fragt nach dem Mac-Passwort (Eingabe wird nicht angezeigt — das ist normal), dann Enter zum Bestätigen. Kann einige Minuten dauern. Danach Homebrew aktivieren:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

B. Node.js installieren

brew install node

Claude Code über npm benötigt Node.js 22 oder neuer. Mit node --version prüfen.

C. Claude Code über npm installieren

npm install -g @anthropic-ai/claude-code

Häufige Stolperfalle (npm): Neuere npm-Versionen blockieren aus Sicherheitsgründen den postinstall-Schritt von Claude Code. Du erkennst das an einer Meldung wie „npm warn allow-scripts … postinstall: node install.cjs“. Dann ist die Installation nur halb fertig und claude funktioniert nicht richtig. Fix — den Script freigeben und neu installieren:

npm approve-scripts @anthropic-ai/claude-code
npm install -g @anthropic-ai/claude-code

Wenn dich das nervt: einfach den nativen Installer aus Schritt 1 nutzen — der hat dieses Problem nicht.

Kein sudo: Installiere niemals mit sudo npm install -g — das führt zu Rechte-Problemen. Und: über Homebrew/npm installiertes Claude Code aktualisiert sich nicht selbst; nutze brew upgrade bzw. npm update -g @anthropic-ai/claude-code.

Checkliste

Alles eingerichtet? Prüfe diese Punkte:

  • Claude Code: claude --version zeigt eine Versionsnummer
  • Einstellungen: cat ~/.claude/settings.json zeigt die JSON-Konfiguration
  • Login: claude startet ohne Fehlermeldung
  • Deutsch: Claude antwortet auf Deutsch
  • Higgsfield (optional): claude mcp list zeigt den Eintrag
  • Diagnose: claude doctor meldet keine Fehler

Was kommt als Nächstes?

Claude Code läuft und ist einsatzbereit. Als Nächstes lohnen sich die MCP-Integrationen (sie erweitern deine Möglichkeiten massiv) und die fertigen Skills.

Die CLAUDE.md Datei

Wenn du in ein Projektverzeichnis navigierst und dort claude startest, sucht Claude Code automatisch nach einer CLAUDE.md. Diese Datei definiert Rolle, Regeln und verfügbare Tools für das Projekt. Du musst sie nicht manuell öffnen — Claude Code liest sie beim Start automatisch.

Memory-System

Claude Code hat ein persistentes Gedächtnis. Sagst du „Merk dir das“, speichert er die Information ab und hat beim nächsten Start automatisch Zugriff darauf. Das Memory unterscheidet:

  • User-Memories: Infos über dich (Rolle, Vorlieben)
  • Feedback-Memories: Korrekturen und bestätigte Vorgehensweisen
  • Project-Memories: Laufende Projekte und Kunden-Infos
  • Reference-Memories: Verweise auf externe Systeme
