Claude Code im Terminal einrichten

Beginner 📖 8 Min. Lesezeit Aktualisiert: Juni 2026

Was ist Claude Code?

Claude Code ist ein KI-Assistent von Anthropic, der direkt in deinem Terminal läuft. Anders als ein normaler Chatbot kann Claude Code Dateien lesen und schreiben, Shell-Befehle ausführen, mit externen Tools interagieren und komplexe, mehrstufige Aufgaben autonom durchführen.

In der Heartbeat Content Engine nutzen wir Claude Code als zentralen Orchestrator für alles von Ad-Erstellung über Design-Automatisierung bis hin zu Kundendaten-Management.

Gut zu wissen: Claude Code ist verfügbar als CLI im Terminal, als Desktop-App (Mac/Windows), als Web-App (claude.ai/code) und als IDE-Extension für VS Code und JetBrains.

Installation

Claude Code wird über npm installiert. Du brauchst dafür Node.js (Version 18+) auf deinem Rechner.

Node.js installieren

Lade Node.js von nodejs.org herunter und installiere es. Prüfe danach im Terminal mit node --version ob es geklappt hat.

Claude Code installieren

Öffne dein Terminal und führe folgenden Befehl aus:

npm install -g @anthropic-ai/claude-code

Anmelden

Starte Claude Code zum ersten Mal mit dem Befehl claude. Du wirst aufgefordert, dich mit deinem Anthropic-Account anzumelden.

Projekt öffnen

Navigiere in dein Projektverzeichnis und starte Claude Code dort. Er erkennt automatisch die CLAUDE.md Datei und konfiguriert sich entsprechend.

cd ~/Repos/heartbeat-content-engine
claude

Die ersten Befehle

Sobald Claude Code läuft, kannst du direkt loslegen. Hier sind die wichtigsten Befehle:

Befehl Was er macht
/help Zeigt alle verfügbaren Befehle und Hilfe an
/skills Listet alle verfügbaren Skills auf
/config Öffnet die Einstellungen (Theme, Modell, etc.)
/clear Löscht den aktuellen Konversations-Verlauf
! befehl Führt einen Shell-Befehl direkt im Terminal aus

Die CLAUDE.md Datei

Die CLAUDE.md Datei im Projektstammverzeichnis ist die zentrale Konfiguration. Sie sagt Claude Code:

  • Welche Rolle er einnehmen soll (z.B. "Heartbeat Content Engine")
  • Welche Tools und APIs verfügbar sind
  • Welche Regeln gelten (z.B. "Kosten immer vorab zeigen")
  • Wie die Projektarchitektur aufgebaut ist

Tipp: Du musst die CLAUDE.md nicht manuell bearbeiten. Claude Code liest sie automatisch beim Start und richtet sich danach. Wenn sich Regeln ändern sollen, sag es einfach Claude Code und er aktualisiert die Datei.

Memory-System

Claude Code hat ein persistentes Gedächtnis. Wenn du sagst "Merk dir das", speichert er die Information als Memory-Datei ab. Beim nächsten Start einer Konversation hat er automatisch Zugriff auf alles Gespeicherte.

Das Memory-System unterscheidet zwischen verschiedenen Typen:

  • User-Memories: Informationen über dich (Rolle, Vorlieben, Expertise)
  • Feedback-Memories: Korrekturen und bestätigte Vorgehensweisen
  • Project-Memories: Laufende Projekte, Deadlines, Kunden-Infos
  • Reference-Memories: Verweise auf externe Systeme und Ressourcen
