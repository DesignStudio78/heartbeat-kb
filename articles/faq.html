Allgemein

Claude Code ist ein KI-Assistent von Anthropic, der im Terminal läuft. Bei Heartbeat nutzen wir ihn als zentrale Content Engine: Er erstellt Ad-Copies, generiert KI-Bilder, baut Figma-Designs, verwaltet Kundendaten und automatisiert wiederkehrende Marketing-Workflows. Alles gesteuert über natürliche Sprache und Slash-Befehle.

Nein. Claude Code versteht natürliche Sprache. Du sagst einfach was du brauchst, z.B. "Erstelle 5 Ads für Casinoverluste" oder tippst /d4y. Claude Code kümmert sich um die technische Umsetzung. Die Skills sind so gebaut, dass du nur die kreativen Entscheidungen triffst.

Claude Code läuft lokal auf deinem Rechner und kommuniziert mit der Anthropic API in der Cloud. Deine Dateien bleiben bei dir — nur die Konversation und Tool-Aufrufe gehen über die API. MCP-Server wie Figma oder Google Drive verbinden sich direkt mit den jeweiligen Cloud-Diensten.

Die CLAUDE.md ist die zentrale Konfigurationsdatei im Projekt. Sie definiert die Rolle von Claude Code ("Heartbeat Content Engine"), verfügbare Tools, Regeln (z.B. "Kosten vorab zeigen") und die Projektarchitektur. Claude Code liest sie automatisch beim Start und richtet sich danach.

MCP-Integrationen

MCP steht für Model Context Protocol. Es ist ein Standard der es Claude Code ermöglicht, mit externen Diensten zu kommunizieren. Jeder MCP-Server ist wie ein Plugin: Der Asana-MCP gibt Claude Code Zugriff auf Projektmanagement, der Figma-MCP auf Design-Tools, usw. Die Konfiguration liegt in der .mcp.json Datei.

Es gibt zwei Wege: (1) OAuth über Claude Web: Für Dienste wie Figma und Higgsfield gehst du auf claude.ai, öffnest die Integrationen und verbindest den Dienst. (2) API Key: Für Dienste wie Close CRM setzt du den API-Key als Umgebungsvariable und trägst den Server in .mcp.json ein. Nach einem Neustart von Claude Code sind die neuen Tools verfügbar.

Das hängt davon ab was du machen willst. Für Ad-Erstellung brauchst du Higgsfield (Bildgenerierung). Für Design-Arbeit den Figma MCP. Für D4Y-Bundles Close CRM (Lead-Daten) + Google Drive (Upload). Für Projektmanagement Asana. Du kannst auch ohne MCPs starten — viele Skills funktionieren rein lokal.

Der Asana MCP verbindet Claude Code mit deinem Projektmanagement. Du kannst Tasks erstellen, Projekte durchsuchen, Subtasks anlegen und Status-Updates abrufen — alles direkt aus der Konversation. Besonders nützlich für automatisierte Workflows: "Erstelle einen Task für jede Ad-Variante die generiert wurde."

Das ist eine feste Regel in der Content Engine: Vor jedem API-Aufruf zur Generierung muss ein Kostenvoranschlag gezeigt und deine explizite Bestätigung eingeholt werden. Das schützt vor versehentlichen Kosten, besonders wenn viele Bilder auf einmal generiert werden. Du musst mit "ja", "ok" oder "mach das" bestätigen.

Claude Code zeigt dir den Fehler und versucht ihn zu analysieren. Häufige Ursachen: API-Limits erreicht, ungültiger Prompt (z.B. zu lang), Netzwerkprobleme oder Modell nicht verfügbar. Claude Code schlägt dann Alternativen vor, z.B. ein anderes Modell oder einen angepassten Prompt. Credits werden nur berechnet wenn die Generierung erfolgreich war.

Bildgenerierung

GPT Image 2 (via Higgsfield): Beste Qualität für alles mit Text-Rendering und Referenzbilder. Nano Banana Pro (Gemini Pro): Günstigste Option für Referenz-basierte Remixes. Seedream 4.5: Bestes Preis-Leistung ohne Referenzen, gut für Portraits. Flux Pro: Höchste Bildqualität für Fotorealismus. Recraft V3: Stark für stilisiertes Design und Illustration. Ideogram V2: Am besten für Text-in-Bild und Logos.

KI-Bildmodelle haben manchmal Probleme mit deutschen Sonderzeichen. Claude Code nutzt deshalb immer echte Umlaute (ü, ä, ö) in Prompts und prüft das Ergebnis nach der Generierung. Wenn Umlaute fehlen oder falsch sind, wird automatisch nachgebessert. Die Regel "NIEMALS ae, oe, ue" ist fest in allen Skills verankert.

Bei Casinoverluste/Jufina in einem datums- und KW-basierten Ordner. Bei Creative Engine werden sie in Airtable als Attachment gespeichert. Der Output-Ordner öffnet sich nach der Generierung automatisch im Finder.

Figma & Design

Ja. Über den Figma MCP kann Claude Code Nodes erstellen, Text bearbeiten, Auto-Layouts aufbauen, Variablen setzen und Komponenten mit Varianten erstellen. Er arbeitet inkrementell — komplexe Designs werden Schritt für Schritt aufgebaut, mit Validierung nach jedem Schritt.

Die Figma API kann nur Cloud-Fonts laden (Google Fonts, Adobe Fonts die in der Figma Cloud verfügbar sind). Lokale Fonts wie Helvetica Now Display funktionieren nicht über die API. Workaround: Verwende eine Cloud-verfügbare Alternative oder setze die Schriftart manuell in Figma nach der automatischen Erstellung.

Troubleshooting

Drücke Ctrl+C um die aktuelle Operation abzubrechen. Wenn das nicht hilft, beende Claude Code mit /exit oder schließe das Terminal. Starte dann neu mit claude. Dein Memory und deine Konfiguration bleiben erhalten. Wenn das Problem bestehen bleibt, prüfe deine Internetverbindung und ob die Anthropic API erreichbar ist.

Prüfe: (1) Ist die .mcp.json korrekt formatiert? (2) Sind die API-Keys/Tokens noch gültig? (3) Ist der MCP-Server-Prozess gestartet? Für OAuth-basierte MCPs (Figma, Higgsfield): Gehe zu Claude Web und erneuere die Verbindung. Für API-Key-basierte MCPs: Prüfe ob die Umgebungsvariable gesetzt ist mit echo $VARIABLE_NAME.

Es gibt zwei Verbindungswege: (1) Primär: MCP über Claude Web (OAuth). Prüfe ob die Airtable-Integration in Claude Web verbunden ist. (2) Fallback: Python REST Client mit PAT in .claude/airtable.json. Prüfe ob der PAT noch gültig ist und die Base-ID (appBcypBUDeVuJkzV) korrekt ist.
