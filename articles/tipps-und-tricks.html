Terminal-Alias: Sofort zu Claude Code springen

Statt jedes Mal cd ~/dein-projekt-ordner && claude zu tippen, legst du dir einen Alias an. Ein Befehl — und du bist drin.

Alias einrichten (Zsh)

Öffne deine ~/.zshrc und füge am Ende hinzu:

# Claude Code Shortcuts
alias cc="cd ~/dein-projekt-ordner && claude"
alias ccc="claude --continue"
alias ccr="claude --resume"

Hinweis: Ersetze ~/dein-projekt-ordner durch den tatsächlichen Pfad zu deinem geklonten Repo, z.B. ~/Repos/mein-projekt oder ~/Documents/content-engine.

Danach einmal neu laden:

source ~/.zshrc

Ab jetzt tippst du nur noch cc und landest direkt in Claude Code im richtigen Projekt.

Tipp: Du kannst für jedes Projekt einen eigenen Alias anlegen: alias cc-projekt2="cd ~/Repos/anderes-projekt && claude". So springst du mit einem Wort in jedes Projekt.

Nützliche Alias-Ideen

Alias Befehl Was er macht
cc cd ~/dein-projekt-ordner && claude Hauptprojekt öffnen
ccc claude --continue Letzte Konversation fortsetzen
ccr claude --resume Bestimmte Session fortsetzen
ccs claude --print-skill-list Alle Skills auflisten

Token-Verbrauch abfragen

Du willst wissen, wie viele Tokens du diesen Monat verbraucht hast? Dafür gibt es ccusage — ein kleines CLI-Tool das dir eine Übersicht gibt.

Aktuellen Monat anzeigen

npx ccusage@latest

Bestimmten Zeitraum abfragen

npx ccusage@latest monthly --since 20260601 --until 20260630

Das zeigt dir eine Aufschlüsselung nach Tagen, Modellen und Gesamtverbrauch. Besonders nützlich um den Überblick über Kosten zu behalten.

Kein Install nötig: npx lädt und führt das Tool direkt aus, ohne es dauerhaft zu installieren.

Markdown-Vorschau mit Flux

Claude Code gibt viel Markdown aus — SKILL.md Dateien, Dokumentation, Notizen. Mit Flux bekommst du eine schicke Live-Vorschau direkt auf dem Mac.

Installation

brew install --cask xykong/tap/flux-markdown

Nach der Installation kannst du jede .md Datei mit Flux öffnen und bekommst eine formatierte Ansicht mit Syntax-Highlighting, Tabellen und Bildern — deutlich besser lesbar als Rohtext im Terminal.

Tipp: Rechtsklick auf eine .md Datei im Finder → "Öffnen mit" → Flux. Du kannst es auch als Standard-App für .md Dateien festlegen.

Remote Control: Claude Code vom Handy steuern

Mit /remote-control kannst du Claude Code von deinem Smartphone aus steuern. Perfekt wenn du am Laptop etwas laufen lassen willst, aber gerade unterwegs bist.

So funktioniert es

Remote Control starten

Tippe /remote-control in Claude Code. Du bekommst einen QR-Code und einen Link.

Auf dem Handy verbinden

Scanne den QR-Code oder öffne den Link auf deinem Smartphone.

Befehle senden

Du kannst jetzt vom Handy aus Text-Inputs an Claude Code schicken. Die Ausgabe siehst du auf dem Laptop.

Use Case: Du startest einen längeren Generierungs-Workflow am Laptop, gehst in die Küche, und bestätigst die Kostenfreigabe bequem vom Handy aus — "ja, generieren".

Asana MCP: Schnell-Setup

Der Asana MCP verbindet Claude Code mit deinem Projektmanagement. Du brauchst einen persönlichen Access Token.

Token erstellen

Asana Developer Console öffnen

Gehe in Asana zu Mein Profil → Apps → Developer Apps → Personal Access Token.

Token generieren

Erstelle einen neuen Token und kopiere ihn. Den Token brauchst du nur einmal — danach ist er in der Konfiguration gespeichert.

In .mcp.json eintragen

Der Token wird als Umgebungsvariable ASANA_ACCESS_TOKEN in der MCP-Konfiguration hinterlegt.

Was du damit machen kannst

  • Tasks erstellen: "Erstelle einen Task für das Logo-Projekt in Asana"
  • Projekte durchsuchen: "Welche Tasks sind diese Woche fällig?"
  • Subtasks anlegen: Automatisch Unteraufgaben für Workflows generieren
  • Status abfragen: "Was ist der Stand beim Onboarding-Projekt?"
