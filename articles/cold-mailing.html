Cold Mailing & E-Mail Copy mit AI

Workflows 📖 7 Min. Lesezeit Aktualisiert: Juni 2026

E-Mail 2: Value Add

Liefere echten Mehrwert ohne Gegenleistung. Ein Quick-Tipp, ein kurzes Framework, eine Beobachtung zu ihrer Website. Zeige Kompetenz, ohne zu verkaufen. Das Ziel: "Die wissen, wovon sie reden."

E-Mail 3: Social Proof

Jetzt wird es konkret: Eine Case Study, ein Ergebnis, ein Testimonial. "Kunde X hatte das gleiche Problem und hat in 3 Monaten Y erreicht." Zahlen schlagen Behauptungen.

E-Mail 4: Objection Handler

Nimm den häufigsten Einwand vorweg und entkräfte ihn. "Die meisten denken, das kostet zu viel Zeit. Tatsächlich brauchen wir nur 30 Minuten für das Setup." Zeige, dass du die Bedenken verstehst.

E-Mail 5: Break-Up

Die letzte E-Mail signalisiert: "Ich respektiere Ihre Zeit." Fasse den Mehrwert in einem Satz zusammen und biete eine einfache Handlungsoption. Kein Druck — aber ein klarer CTA.

Betreffzeilen: 3 Varianten pro E-Mail

Claude Code generiert automatisch 3 Betreffzeilen-Varianten pro E-Mail — zum A/B-Testen. Jede Variante folgt einer anderen Strategie:

Variante Strategie Beispiel
A — Direkt Pain Point benennen "Ihr Lead-Prozess kostet Sie Deals"
B — Neugier Offene Schleife erzeugen "Was Ihre Top-3-Wettbewerber anders machen"
C — Persönlich Bezug zum Empfänger "Kurze Frage zu [Firmenname]"

Regel: Betreffzeilen dürfen maximal 50 Zeichen lang sein. Alles darüber wird in mobilen E-Mail-Clients abgeschnitten — und dort werden über 60% aller E-Mails gelesen.

Das Marketing Offer Framework

Bevor Claude Code die Sequenz schreibt, braucht er den richtigen Input. Das Marketing Offer Framework definiert die Bausteine:

  • Zielgruppe: Wer ist der Empfänger? (Rolle, Branche, Unternehmensgröße)
  • Pain Point: Welches Problem hat die Zielgruppe? (Konkret, messbar)
  • Angebot: Was bietest du an? (Nicht das Produkt, sondern das Ergebnis)
  • Social Proof: Welche Ergebnisse hast du erzielt? (Zahlen, Namen, Zeiträume)
  • Einwand: Was hält Empfänger typischerweise zurück?
  • CTA: Was ist der nächste Schritt? (Kalenderbuchung, Antwort, Link)

Je präziser diese Inputs, desto besser die generierten E-Mails. Vage Inputs ergeben generische E-Mails — konkrete Inputs ergeben E-Mails, die konvertieren.

Die Regeln für gute Cold Mails

Claude Code hält sich strikt an diese Constraints — und du solltest das auch bei manuellen Anpassungen tun:

Regel Warum
Deutsche Sprache, Sie-Form Professioneller B2B-Ton im DACH-Raum
Max. 150 Wörter pro E-Mail Kurze E-Mails werden gelesen, lange werden ignoriert
Max. 50 Zeichen Betreffzeile Vollständige Anzeige auf Mobile
Keine Spam-Trigger-Wörter "Kostenlos", "Angebot", "Jetzt kaufen" landen im Spam
Ein CTA pro E-Mail Mehrere CTAs verwässern die Handlungsaufforderung
Kein HTML, kein Design Plain-Text-Mails haben höhere Zustellraten

Tools & Integration

Die Cold-Mailing-Pipeline nutzt zwei Schlüssel-Integrationen:

Close CRM via MCP

Claude Code kann über den Close-MCP-Server direkt auf Lead-Daten zugreifen: Firmennamen, Ansprechpartner, Branche, bisherige Interaktionen. Diese Daten fließen in die Personalisierung der E-Mails ein.

# So nutzt der Skill Close-Daten:

2. Firma, Ansprechpartner, Branche extrahieren
3. Marketing Offer Framework befüllen
4. Personalisierte 5-E-Mail-Sequenz generieren
5. Als Markdown oder direkt als Close-Sequenz speichern

Der /cold-mailing Skill

Der fertige Skill lässt sich mit einem Befehl starten:

# Aufruf:
/cold-mailing

# Claude Code fragt dann:
# → Zielgruppe?
# → Angebot/Ergebnis?
# → Vorhandener Social Proof?
# → Close Lead-Daten einbeziehen? (ja/nein)

Praxis-Tipp: Generiere zuerst eine Sequenz für dein wichtigstes Kundensegment. Teste sie manuell mit 20–30 Empfängern und miss die Reply-Rate. Erst wenn die Baseline steht, skalierst du auf weitere Segmente und automatisierte Sends.

Beispiel-Output: E-Mail 1 (Cold Opener)

Betreff A: "3 Deals pro Woche bleiben auf der Strecke"
Betreff B: "Was zwischen Erstkontakt und Abschluss passiert"
Betreff C: "Kurze Frage zu [Firmenname]s Pipeline"

---

Guten Tag Herr Müller,

die meisten B2B-Dienstleister verlieren ihre besten
Leads zwischen dem ersten und dritten Touchpoint.
Nicht weil das Angebot schlecht ist — sondern weil
die Follow-up-Sequenz fehlt.

Wir haben für drei Agenturen im DACH-Raum genau
dieses Problem gelöst. Das Ergebnis: 40% mehr
gebuchte Erstgespräche bei gleichem Lead-Volumen.

Wäre ein kurzer Austausch dazu interessant?

Beste Grüße
[Name]

Beachte: 87 Wörter, ein konkretes Problem, ein konkretes Ergebnis, ein klarer CTA. Kein Smalltalk, kein "Ich bin XY und wir machen ABC".
