Higgsfield: KI-Bilder & Videos direkt aus Claude Code

Generierung 📖 10 Min. Lesezeit Aktualisiert: Juni 2026
Video: Bilder generieren mit Higgsfield

Was ist Higgsfield?

Higgsfield ist eine KI-Plattform die verschiedene Generierungs-Modelle unter einem Dach vereint. Über den MCP-Server kannst du direkt aus Claude Code Bilder, Videos und Audio erstellen — ohne die Plattform separat öffnen zu müssen.

Verfügbare Modelle

Typische Einsatzgebiete

Ad-Creatives

Der häufigste Einsatz: Bilder für Werbe-Creatives generieren. Claude Code formuliert den Prompt basierend auf Marken-CI, Zielgruppe und Botschaft, und Higgsfield generiert das Bild.

"Generiere 3 Ad-Bilder für Casinoverluste.at
im NEON-Poppy Stil mit 3D Casino-Elementen"

D4Y LinkedIn Starter Bundle

Beim /d4y-higgsfield Workflow werden automatisch 3 Bilder generiert:

  • 2 Bilder mit Prompt 1 (Hauptmotiv + Produkt)
  • 1 Bild mit Prompt 2 (alternative Perspektive)
  • Auflösung: 1024×1024px (Standard) oder höher

Logo-Design

Der /logo Skill nutzt Higgsfield (GPT Image 2) um Konzept-Visualisierungen zu erstellen. Basierend auf 8 Angle-Templates werden verschiedene Logo-Konzepte generiert.

Soul Characters: Mit /higgsfield-soul-id kannst du konsistente Personen-Identitäten erstellen, die über mehrere Generierungen hinweg gleich aussehen. Perfekt für Testimonial-Serien oder Brand-Ambassadors.

Bilder hochladen und referenzieren

Du kannst eigene Bilder als Referenz nutzen:

  • Lokale Bilder: Über media_upload_widget in Claude Web hochladen
  • Web-URLs: Werden automatisch über media_import_url importiert
  • Vorherige Generierungen: Job-IDs können als Input für neue Generierungen dienen

Best Practices

  • Umlaute: IMMER echte Umlaute (ü, ä, ö) in Prompts verwenden
  • Akzentfarben: Farbe explizit mit CRITICAL_COLOR_INSTRUCTION im Prompt erzwingen
  • Hintergründe: Aggressive Flat-Solid-Instruktion gegen Artefakte bei Gemini-Modellen
  • Weiße Flächen: CRITICAL WHITE SURFACE RULE im Prompt, da Gemini weiße Cards verschmutzt
  • Keine URLs/Logos: Niemals Domains oder Logos auf generierte Bilder setzen

Verbindung einrichten

Higgsfield-Account erstellen

Registriere dich auf Higgsfield und sichere dir Credits für die Generierung.

Über Claude Web verbinden

Verbinde Higgsfield über die OAuth-Integration in Claude Web (claude.ai → Integrationen).

Workspace auswählen

Wähle deinen Higgsfield Workspace aus, in dem die Generierungen landen sollen.

Kosten im Blick behalten

Claude Code zeigt dir immer einen Kostenvoranschlag bevor generiert wird. Du musst explizit bestätigen ("ja", "ok", "mach das") bevor Credits verbraucht werden. Diese Regel ist fest in der Content Engine verankert.
