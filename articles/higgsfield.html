Higgsfield: KI-Bilder & Videos direkt aus Claude Code

Generierung 📖 10 Min. Lesezeit Aktualisiert: Juni 2026

Was ist Higgsfield?

Higgsfield ist eine KI-Plattform, die verschiedene Bild- und Video-Modelle unter einem Dach vereint. Über den MCP-Server kannst du direkt aus Claude Code im Terminal Bilder und Videos generieren — ohne eine Website zu öffnen oder manuell Dateien hochzuladen.

Du sagst Claude Code einfach was du brauchst, z.B. "Generiere ein Bild von einem modernen Büro im minimalistischen Stil" — und Higgsfield erstellt es.

Higgsfield in Claude Code einrichten

Die Einrichtung besteht aus einem einzigen Terminal-Befehl. Die Anmeldung passiert danach automatisch.

Voraussetzung: Claude Code muss bereits installiert sein (Setup-Anleitung). Falls Claude Code gerade läuft, zuerst mit Ctrl+C oder /exit beenden.

Schritt 1: MCP-Server hinzufügen

Diesen Befehl im Terminal eingeben (nicht in Claude Code, sondern in der normalen Shell):

claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp

Das war's. Der MCP-Server ist registriert.

Schritt 2: Prüfen

claude mcp list

In der Liste sollte higgsfield mit der URL https://mcp.higgsfield.ai/mcp erscheinen.

Schritt 3: Erstes Bild generieren

Claude Code starten und direkt loslegen:

claude

Dann in Claude Code tippen:

Generiere mir ein Bild von einem Sonnenuntergang am Meer.

Was jetzt passiert: Beim ersten Mal öffnet sich automatisch ein Browser-Fenster. Dort mit dem Higgsfield Marketing-Account einloggen und den Zugriff bestätigen. Das musst du nur einmal machen — danach funktioniert es dauerhaft.

Verfügbare Bildmodelle

Higgsfield bündelt verschiedene KI-Modelle. Die drei wichtigsten für unsere Arbeit:

Nano Banana Pro (Gemini 3 Pro) Sehr gute Qualität, Referenzbild-basiert Remixes von Produkt-Fotos, Varianten mit Referenzbildern
Nano Banana 2 (Gemini 3.1 Flash) Schnell, günstig, solide Qualität Schnelle Entwürfe, Iterationen, wenn Geschwindigkeit zählt

Weitere Modelle

Was du mit Higgsfield machen kannst

Bilder generieren (Text-to-Image)

Beschreibe was du brauchst — Claude Code formuliert den Prompt und Higgsfield generiert:

Generiere ein Bild: Modernes Büro mit Glaswänden,
warmes Licht, minimalistisch, 4K Qualität.

Bilder aus Referenzen erstellen (Image-to-Image)

Du kannst ein bestehendes Bild als Referenz nutzen. Entweder per URL oder indem du Claude Code auf eine lokale Datei verweist:

Nimm dieses Produktfoto als Referenz und erstelle
eine Version mit dunklem Hintergrund und Neon-Akzenten:
[Bild-URL oder Dateipfad]

Videos erstellen

Text-to-Video oder Image-to-Video — Claude Code wählt automatisch das passende Videomodell:

Erstelle ein kurzes Video: Kaffeetasse auf einem Tisch,
Dampf steigt auf, Kamerazoom, cinematisch.

Bilder bearbeiten

  • Hintergrund entfernen: "Entferne den Hintergrund von diesem Bild"
  • Upscaling: "Skaliere dieses Bild auf 4K hoch"
  • Outpainting: "Erweitere das Bild nach rechts"

Soul Characters

Mit Soul Characters kannst du eine konsistente Personen-Identität erstellen, die über mehrere Generierungen hinweg gleich aussieht. Perfekt für Testimonial-Serien oder wiederkehrende Figuren in Ads.

Typische Einsatzgebiete bei uns

Ad-Creatives

Der häufigste Einsatz: Bilder für Werbe-Creatives generieren. Claude Code kennt die Marken-CI und formuliert den Prompt entsprechend:

Generiere 3 Ad-Bilder im dunklen, cineastischen Stil
mit 3D-Elementen und orangenen Akzenten.

D4Y LinkedIn Starter Bundle

Beim /d4y Workflow werden automatisch 3 Bilder generiert: 2 mit dem Hauptmotiv und 1 mit alternativer Perspektive. GPT Image 2 ist dabei der Standard.

Logo-Design

Der /logo Skill nutzt GPT Image 2 um verschiedene Logo-Konzepte zu visualisieren, basierend auf 8 Angle-Templates.

Best Practices

  • Deutsche Umlaute: IMMER echte Umlaute (ü, ä, ö) in Prompts verwenden, nie ue/ae/oe
  • Akzentfarben erzwingen: Wenn du eine bestimmte Farbe brauchst, explizit im Prompt nennen — z.B. "Akzentfarbe MUSS exakt Orange #FB841C sein"
  • Flache Hintergründe: Wenn der Hintergrund einfarbig sein soll, explizit "flat solid background" im Prompt angeben — sonst entstehen Artefakte
  • Weiße Flächen: Bei weißen Cards/Flächen explizit "pure clean white surface, no texture, no grain" angeben
  • Keine URLs/Logos: Niemals Domains oder Logos auf generierte Ad-Bilder setzen
  • Keine echten Geldscheine: Kein reales Geld auf Creatives zeigen

Higgsfield Plugins für Video-Editoren

Higgsfield bietet auch native Plugins für professionelle Video-Editoren:

  • Adobe Premiere Pro & After Effects: 5 AI-Plugins direkt in der Timeline — Reframe, Hintergrund entfernen, Upscale, Draw to Edit, Video bearbeiten. Kein Exportieren nötig.
  • DaVinci Resolve: Gleiche AI-Funktionen direkt in DaVinci.

Kosten im Blick

Claude Code zeigt dir immer einen Kostenvoranschlag bevor generiert wird. Du musst explizit bestätigen ("ja", "ok", "mach das") bevor Credits verbraucht werden. So entstehen keine unerwarteten Kosten.
