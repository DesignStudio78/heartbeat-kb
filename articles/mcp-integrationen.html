MCP-Server: Was sie können und wie du sie verbindest

Integrationen 📖 6 Min. Lesezeit Aktualisiert: Juni 2026

Was sind MCP-Server?

MCP steht für Model Context Protocol. Es ist ein offener Standard, der es Claude Code ermöglicht, mit externen Tools und Diensten zu kommunizieren. Stell dir MCPs wie Plugins vor: Jeder MCP-Server gibt Claude Code neue Fähigkeiten.

Ohne MCPs kann Claude Code nur mit lokalen Dateien und dem Terminal arbeiten. Mit MCPs kann er plötzlich Figma-Designs erstellen, Asana-Tasks verwalten, Google-Docs bearbeiten oder KI-Bilder generieren.

Wie es funktioniert: Die MCP-Konfiguration liegt in der .mcp.json Datei im Projektverzeichnis. Claude Code verbindet sich beim Start automatisch mit allen konfigurierten Servern.

Verfügbare Integrationen

Asana MCP — Projektmanagement

Der Asana MCP verbindet Claude Code mit deinem Asana-Workspace. Du kannst damit:

  • Tasks erstellen und verwalten — "Erstelle einen Task für das neue Logo-Projekt"
  • Projekte durchsuchen — "Welche Tasks sind diese Woche fällig?"
  • Subtasks anlegen — Automatisch Unteraufgaben für komplexe Workflows erstellen
  • Status-Updates lesen — Projektstatus direkt in der Konversation abrufen
Video: Asana MCP in Aktion

Figma MCP — Design-Automatisierung

Der Figma MCP ist einer der mächtigsten Integrationen. Er erlaubt Claude Code, direkt in Figma-Dateien zu arbeiten:

  • Designs auslesen — Screenshots, Metadaten, Komponentenstruktur
  • Nodes erstellen und bearbeiten — Frames, Text, Formen, Auto-Layouts
  • Design Systeme aufbauen — Variablen, Tokens, Komponenten mit Varianten
  • Design-to-Code — Figma-Designs als Code-Referenz exportieren
  • Code-to-Design — HTML/Code-Layouts zurück nach Figma pushen

Mehr dazu im Figma MCP Deep Dive.

Google Drive MCP — Dateiverwaltung

Mit dem Google Drive MCP kann Claude Code auf dein gesamtes Google Drive zugreifen:

  • Dateien suchen und lesen — Dokumente, Sheets, Präsentationen
  • Dateien erstellen und bearbeiten — Google Docs und Sheets direkt beschreiben
  • Ordner verwalten — Dateien verschieben, Ordner erstellen
  • Bilder hochladen — Generierte Creatives direkt in Drive-Ordner speichern

Typischer Einsatz: Beim D4Y-Workflow werden fertige Ad-Bilder automatisch in einen kundenspezifischen Google Drive Ordner hochgeladen, damit der Kunde sofort Zugriff hat.

Higgsfield MCP — KI-Bild- & Videogenerierung

Higgsfield ist die zentrale Plattform für KI-Generierung. Über den MCP kannst du:

  • Bilder generieren — GPT Image 2, Flux, Seedream, Recraft und mehr
  • Videos erstellen — Text-to-Video, Image-to-Video, Animationen
  • Soul Characters nutzen — Konsistente Gesichter/Identitäten über mehrere Bilder
  • Bilder bearbeiten — Upscaling, Hintergrund entfernen, Outpainting

Mehr dazu im Higgsfield Deep Dive.

Close CRM MCP — Sales & Lead-Management

Der Close CRM MCP verbindet Claude Code mit deinem Vertriebssystem:

  • Lead-Daten abrufen — Kontaktinfos, Unternehmensdaten, Notizen
  • Opportunities verwalten — Deal-Status aktualisieren
  • Tasks erstellen — Follow-up-Aufgaben direkt aus der Konversation
  • Suche — Leads nach Name, Status oder Custom Fields filtern

Typischer Einsatz: Beim D4Y-Workflow zieht Claude Code automatisch die Lead-Daten aus Close (Firmenname, Logo, Angebot), um daraus personalisierte Ad-Creatives zu erstellen.

Einen MCP verbinden

MCPs werden in der .mcp.json Datei konfiguriert. Die meisten MCPs nutzen entweder OAuth (z.B. Figma, Higgsfield über Claude Web) oder API-Keys (z.B. Close CRM, Google Drive).
