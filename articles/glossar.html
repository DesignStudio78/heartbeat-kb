Glossar — unsere AI-Sprache einfach erklärt

Cheat Sheet 📖 Zum Nachschlagen Aktualisiert: Juni 2026
Claude Code GitHub & Zusammenarbeit Web & Technik Tools & Sonstiges

Wichtigster Tipp: Du musst dir nichts davon merken. Wenn ein Wort unklar ist, frag im Zweifel einfach Claude direkt — z.B. Was ist eine .md-Datei? oder Erklär mir was "pushen" bedeutet. Claude erklärt dir alles auf deinem Wissensstand. Dieses Glossar ist nur zum schnellen Nachschlagen da.

Claude Code & Grundlagen

16 Begriffe
Claude Code

Der KI-Assistent, der im Terminal oder in der App läuft, Code schreibt, Dateien bearbeitet und Tools steuert. („Cloud Code" ist nur ein Transkriptions-Hörfehler — gemeint ist immer Claude.)

Prompt / prompten

Die Anweisung, die du Claude in Textform gibst. Prompten heißt: Claude per Text beauftragen. Je klarer der Prompt, desto besser das Ergebnis.

Skill

Ein vorgefertigter Workflow, den du mit Schrägstrich startest, z.B. /d4y oder /ad-session. Wie eine gespeicherte Arbeitsanleitung, die Claude Schritt für Schritt abarbeitet.

MCP
Model Context Protocol

Die Schnittstelle, die Claude mit externen Tools verbindet — Figma, Asana, Google Drive, Higgsfield, Close CRM usw. Über MCPs kann Claude diese Programme direkt bedienen.

.md / Markdown

Eine einfache Textdatei mit leichter Formatierung (# = Überschrift, **fett**). KI kann sie perfekt lesen & schreiben — deshalb arbeiten wir mit Markdown statt mit Google Docs.

CLAUDE.md / Rules

Die Regel-Datei in einem Projekt, die Claude sagt, wie er sich verhalten soll (Architektur, Sprache, Styling). Wie „Leitplanken", damit nichts schiefgeht.

Memory / Memories

Gespeicherte Fakten, die Claude über mehrere Sessions hinweg behält — z.B. Vorlieben, Kunden-Infos oder wiederkehrende Regeln.

Context Window / Kontext

Wie viel Claude gleichzeitig „im Kopf" behalten kann. Wird ein Chat sehr lang, fällt Älteres hinten raus — dann lieber neuen Chat starten.

Token

Die Recheneinheit für Text (grob: Wortteile). Bestimmt sowohl die Kosten als auch, wie viel in den Kontext passt.

Plan-Modus

Claude plant erst und baut nicht sofort. Ideal für größere Features oder Webseiten, die du vorher gemeinsam durchdenken willst.

Auto-Modus
„dangerously skip permissions"

Claude darf handeln, ohne bei jedem Schritt nachzufragen. Schneller, wenn du dem Ablauf vertraust.

Permissions

Die Erlaubnis-Abfragen, bevor Claude etwas ausführt (Datei ändern, Befehl starten). Am Anfang gut, um zu sehen, was passiert.

Opus / Sonnet / Haiku / Fable

Die verschiedenen Claude-Modelle. Opus = das stärkste. Höhere Zahl = neuer (z.B. Opus 4.8 ist besser als 4.6).

Claude Design
im Meeting „Cloud Design"

Claudes Design-Tool im Browser. Baut aus einem Prompt richtig gute Slides, Webseiten oder Freebies — Logo & Texte einfach mitgeben.

Terminal

Das schwarze Eingabefenster, in dem man Befehle tippt — und Claude Code startet (mit Pfeiltaste nach oben holst du den letzten Befehl zurück).

Code / Cowork (App)

Zwei Claude-Oberflächen. Code ist nah am Terminal (gut für Webseiten), Cowork ist einfacher (gut für Skills) — für viele Aufgaben austauschbar.

GitHub & Zusammenarbeit

9 Begriffe
GitHub

Plattform zum Speichern, Versionieren und gemeinsamen Bearbeiten von Code. Salopp: „wie Google Drive, nur besser für KI." Nie verlierst du deinen Stand.

Repo / Repository

Ein Projekt-Ordner auf GitHub. Enthält den ganzen Code eines Projekts (z.B. eine Webseite samt Skills und Regeln).

clone / klonen

Ein Repo als Kopie auf deinen eigenen Computer holen, um daran zu arbeiten.

commit / committen

Einen Zwischenstand lokal auf deinem Computer speichern — wie ein Schnappschuss, zu dem du jederzeit zurück kannst.

push / pushen

Deine lokalen Commits zu GitHub hochladen, damit alle anderen sie sehen. Faustregel am Anfang: committen ja, pushen erst, wenn du sicher bist.

pull / pullen

Die neuesten Änderungen von GitHub zu dir herunterholen — so bekommst du den aktuellen Stand der Kollegen.

merge / mergen

Verschiedene Arbeitsstände wieder zusammenführen — auch wenn mehrere Leute parallel gearbeitet haben, ohne sich gegenseitig zu überschreiben.

Branch

Ein separater Arbeitsstrang („Zweig"), in dem du etwas ausprobieren kannst, ohne den Hauptstand zu stören. Später wird er gemerged.

gh / GitHub CLI

Das Kommandozeilen-Tool, mit dem Terminal & Claude sich mit GitHub verbinden. Einmal authentifizieren — danach bist du dauerhaft eingeloggt.

Web & Technik

11 Begriffe
Localhost

Eine Vorschau-Webseite, die nur auf deinem Computer läuft. Niemand sonst hat Zugriff — ein Localhost-Link lässt sich nicht teilen.

Domain

Die öffentliche Web-Adresse einer Seite (z.B. beispiel.com). Erst mit Domain ist eine Seite für andere im Internet erreichbar.

Dev-Server / „Dev"

Der lokale Entwicklungsmodus, der deine Seite zum Testen live anzeigt (z.B. via astro dev). Änderungen erscheinen sofort.

Astro

Das Web-Framework, mit dem unsere Webseiten und Blogs gebaut sind — schnell und gut für SEO.

VS Code

Der weltweit verbreitetste Code-Editor. Gibt dir eine gute Oberfläche, um Dateien, Commits und Stände im Blick zu behalten.

API

Eine Schnittstelle, über die Programme Daten austauschen — z.B. um Daten von YouTube oder Spotify automatisch abzufragen.

JSON

Ein strukturiertes Datenformat. Wird für Daten und manchmal für komplexe, lange Prompts verwendet.

Frontend

Der sichtbare Teil einer Webseite — alles, was der Nutzer im Browser sieht (Design, Buttons, Texte).

SEO

Suchmaschinen-Optimierung. Sorgt dafür, dass Google & KIs uns gut finden — über sinnvolle Struktur, Unterseiten und Keywords.

scrapen

Daten automatisch von einer Webseite einsammeln (z.B. Bewertungen), um sie weiterzuverarbeiten.

Pipeline

Eine automatisierte Abfolge von Schritten, die nacheinander laufen — z.B. Daten sammeln → aufbereiten → einbauen.

Tools & Sonstiges

6 Begriffe
Transkribierungstool
Wispr Flow / Super Whisper

Wandelt deine gesprochene Stimme in Text um. Macht das Prompten viel schneller — einfach reden statt tippen. Im Alltag fast unverzichtbar.

Figma

Das Design-Tool für Layouts und Komponenten. Per MCP mit Claude verbunden, sodass Designs direkt erstellt/bearbeitet werden können.

Higgsfield

KI-Tool für Bild- und Video-Generierung (per MCP angebunden). Damit entstehen z.B. Ad-Creatives und Marketing-Videos.

ffmpeg

Ein Kommandozeilen-Tool zum Schneiden und Konvertieren von Video & Audio — z.B. um Podcast-Clips automatisch herauszuschneiden.

Knowledge Base

Diese Sammlung hier — die zentrale Wissens-Seite mit Anleitungen, MCPs, Skills und diesem Glossar.

Ramp-up

Die Einarbeitungs- bzw. Hochfahr-Phase auf ein neues Thema oder Tool.
