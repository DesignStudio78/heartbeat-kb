Freebies & Lead Magnets: Von Text bis Design

Workflows 📖 10 Min. Lesezeit Aktualisiert: Juni 2026

2. JSON Config

Der Text wird in eine strukturierte JSON-Konfiguration überführt. Jede Seite bekommt ihren eigenen Block mit Typ (Cover, Content, CTA), Texten, Layout-Hinweisen und Styling-Parametern. Das JSON ist die Brücke zwischen Text und Design.

3. HTML-Seiten

Aus dem JSON werden pixel-perfekte HTML-Seiten generiert — eine pro Freebie-Seite. Jede Seite hat exakt 595 × 842px (A4-Proportionen). Das HTML nutzt echte Typografie, CSS-Grid-Layouts und die Brand-CI des Kunden.

4. PDF Export

Die HTML-Seiten werden zu einem mehrseitigen PDF zusammengefügt. Das Ergebnis ist ein druckfertiges Dokument, das direkt als Download-Asset auf der Landingpage verwendet werden kann.

5. Figma Push

Automatisch — ohne Rückfrage — wird das fertige Freebie in die zentrale Figma-Datei gepusht. Dort kann es weiter angepasst, von Designern reviewed oder als Vorlage für zukünftige Freebies genutzt werden.

Freebie-Typen im Vergleich

Typ Seitenanzahl Ziel Bester Einsatz
Playbook 8–15 Seiten Tiefes Wissen vermitteln Komplexe Themen, Strategy-Frameworks
Guide 5–10 Seiten Schritt-für-Schritt-Anleitung How-to-Content, Einsteiger-Themen
Checklist 2–4 Seiten Schnelle Umsetzung ermöglichen Audits, Checklisten, Quick Wins

Design-Regeln: Was der Skill erzwingt

Gutes Freebie-Design folgt strengen Regeln. Der /freebie-generator Skill kennt diese Regeln und wendet sie automatisch an:

  • Content oben: Der Inhalt beginnt immer am oberen Seitenrand. Kein Leerraum, kein "atmendes" Layout. Freebies werden am Screen gelesen — der Platz über dem Fold ist heilig.
  • Pills inline: Tags und Kategorie-Labels (Pills) werden inline gesetzt, nicht als separate Zeile. Das spart vertikalen Platz.
  • Footer konsistent: Jede Seite hat den gleichen Footer mit Logo und Seitenzahl. Keine Variation, kein "kreativer" Footer.
  • Format 595 × 842px: Dieses Format entspricht A4-Proportionen und funktioniert sowohl am Screen als auch im Druck.
  • Keine Spacer-Rechtecke: Abstände werden über Auto-Layout und itemSpacing gesteuert, nie über unsichtbare Rechteck-Elemente.

Wichtig: Der Skill pusht das Freebie automatisch in Figma — du wirst nie gefragt "Soll ich das in Figma laden?". Das passiert immer. Alle Freebies landen im zentralen DOKUMENTE-File.

Die CTA-Seite

Die letzte Seite jedes Freebies ist immer eine Call-to-Action-Seite. Sie nutzt eine vordefinierte Figma-Komponente und enthält:

  • Einen klaren Handlungsaufruf ("Jetzt Erstgespräch buchen")
  • Die wichtigsten 2–3 Argumente als Bullet Points
  • Kontaktdaten oder Booking-Link
  • Das Kunden-Logo

Die CTA-Component wird automatisch auf der letzten Seite eingebunden. Das stellt sicher, dass jedes Freebie mit einer klaren Handlungsaufforderung endet — nicht mit einem "Das war's".

Figma Capture: Von HTML zu Figma

Der Figma-Push nutzt die Figma MCP-Integration. Der Workflow im Detail:

# Figma Capture Workflow
1. HTML-Seiten rendern (595 x 842px pro Seite)
2. Figma-Frames erstellen (fixed size, nie HUG)
3. Texte als echte Text-Nodes einsetzen
4. Bullets als echte HTML-Bullets (kein ::before Hack)
5. Cards mit gleicher Höhe im Grid
6. Container-Höhen korrekt setzen
7. Library-Komponenten für Header/Footer laden
8. CTA-Component auf letzter Seite einbinden
9. Auto-Layout mit korrektem itemSpacing

Technisches Detail: Figma-Seiten werden IMMER mit fester Größe (595 × 842px) erstellt, nie mit HUG. HUG würde dazu führen, dass Seiten unterschiedlich groß werden — das zerstört die PDF-Konsistenz.

Qualitätschecks beim Figma Capture

Der Skill prüft automatisch nach dem Push:

  • Bullets: Echte Text-Bullets, keine ::before Pseudo-Elemente
  • Container-Höhen: Alle Content-Container haben die korrekte Höhe
  • Card-Grid: Karten in einem Grid haben exakt gleiche Höhe
  • Fonts: Nur Cloud-kompatible Fonts (die Figma API kann keine lokalen Fonts laden)
  • Bilder: Immer 4K PNG, niemals komprimierte JPGs

Praxis-Tipp: Starte mit einem Playbook für dein Kernthema. Nutze es als Vorlage: Wenn das Design und die Struktur stehen, können Guide- und Checklist-Varianten in wenigen Minuten davon abgeleitet werden.
