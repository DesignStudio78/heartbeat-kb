SEO & Blog Pipeline: Automatisierter Content

Fortgeschritten 📖 8 Min. Lesezeit Aktualisiert: Juni 2026

2. Content-Generierung

Aus einer Keyword-Liste generiert Claude Code vollständige Blogposts: Titel, Meta-Description, Struktur mit H2/H3, Fließtext, interne Verlinkung und Call-to-Actions. Jeder Post wird als Draft in Storyblok angelegt.

3. SEO-Optimierung

Der SEO-Audit-Skill prüft jeden Post automatisch: Keyword-Dichte, Meta-Tags, Alt-Texte, interne Links, Lesezeit, Schema-Markup. Fehlt etwas, wird es direkt korrigiert.

4. Review & Freigabe

Du prüfst die generierten Drafts in Storyblok. Passt alles? Ein Klick auf "Publish" macht den Post live. Willst du etwas ändern? Sag Claude Code was nicht stimmt, der Rest läuft automatisch.

5. Build & Deploy

Nach dem Publish triggert ein Webhook den Astro-Build. Die Seite wird neu generiert und automatisch auf Vercel oder Netlify deployed. Innerhalb von Sekunden ist der neue Post live.

Der SEO-Audit-Skill

Das Herzstück der Pipeline ist ein dedizierter SEO-Audit-Skill, der nach jedem Build automatisch laufen kann. Er prüft:

  • On-Page SEO: Title-Tag Länge (50–60 Zeichen), Meta-Description (150–160 Zeichen), H1-Eindeutigkeit, Keyword im ersten Absatz
  • Technisches SEO: Canonical-Tags, robots.txt, Sitemap-Vollständigkeit, Ladegeschwindigkeit, Mobile-Friendliness
  • Content-Qualität: Wortanzahl (min. 800 Wörter für Blogposts), Lesefluss, Absatzlänge, Bild-Alt-Texte
  • Interne Verlinkung: Mindestens 2–3 interne Links pro Post, keine Broken Links, sinnvolle Ankertexte
# Beispiel: SEO-Audit-Skill Struktur
.claude/skills/seo-audit/
├── SKILL.md
├── references/
│   ├── seo-checklist.md      # Vollständige Prüfliste
│   ├── schema-templates.md   # JSON-LD Schema-Vorlagen
│   └── keyword-rules.md      # Keyword-Dichte, Platzierung
└── scripts/
    └── audit.py              # Automatischer Check nach Build

Konzept-Idee: Der SEO-Audit-Skill kann als Post-Build-Hook konfiguriert werden. Jedes Mal wenn Astro baut, läuft der Audit automatisch und meldet Probleme direkt in Claude Code. So rutscht kein unoptimierter Post durch.

Die Vision: Multi-Domain Content

Einmal aufgesetzt, lässt sich die Pipeline auf mehrere Domains skalieren. Stell dir vor:

  • Domain A: Firmenblog mit Thought-Leadership-Content
  • Domain B: Nischen-Affiliate-Seite mit Produktvergleichen
  • Domain C: Kunden-Blog im Managed-Service

Jede Domain hat ihr eigenes Astro-Repo und ihren eigenen Storyblok-Space, aber alle werden über die gleiche Claude-Code-Pipeline befüllt. Die Content-Generierung folgt domain-spezifischen Regeln (Tonalität, Keywords, Zielgruppe), der technische Workflow bleibt identisch.

Wie weit kann Automatisierung gehen?

Vollautomatische Content-Produktion klingt verlockend — aber es gibt klare Grenzen:

  • Was gut automatisierbar ist: Recherche, Struktur, erste Entwürfe, SEO-Checks, technisches Deployment, Meta-Daten, Schema-Markup
  • Was menschliche Kontrolle braucht: Finale Freigabe, Brand Voice, kontroverse Themen, Fakten-Checks bei sensiblen Inhalten, strategische Themenplanung
  • Was du nicht automatisieren solltest: Thought-Leadership-Pieces ohne eigene Expertise, Content über Themen die du nicht verstehst, "Me-too"-Content ohne eigenen Winkel

Die Pipeline ist ein Werkzeug, kein Ersatz für redaktionelle Qualität. Sie nimmt dir die Fleißarbeit ab, damit du dich auf Strategie und Qualitätskontrolle konzentrieren kannst.

Praxis-Tipp: Starte mit 2–3 Blogposts pro Woche und überprüfe nach einem Monat die Rankings. Erst wenn der Workflow sitzt und die Qualität stimmt, skalierst du auf tägliches Publishing oder mehrere Domains.
