Figma MCP: Designs lesen, erstellen und bearbeiten

Deep Dive 📖 12 Min. Lesezeit Aktualisiert: Juni 2026
Video: Figma MCP Workflow Demo

Was kann der Figma MCP?

Der Figma MCP ist die Brücke zwischen Code und Design. Er nutzt die offizielle Figma Plugin API und kann alles tun, was du manuell in Figma machen könntest — und vieles mehr, weil Claude Code Logik und Automatisierung hinzufügt.

Kernfähigkeiten

  • Design Context lesen: Screenshots, Code-Referenz und Metadaten von jedem Node auslesen
  • Nodes erstellen: Frames, Text, Formen, Auto-Layouts — alles programmatisch
  • Komponenten bauen: Component Sets mit Varianten, Properties und Auto-Layout
  • Variablen verwalten: Collections, Modes (Light/Dark), Token-Hierarchien
  • Text-Styles: Typography Ramps mit Font-Bindings erstellen
  • Assets verwalten: Bilder hochladen, Thumbnails exportieren

Typische Workflows

1. Design-to-Code

Du gibst Claude Code eine Figma-URL und er extrahiert die Design-Informationen:

"Implementiere dieses Design aus Figma:
https://figma.com/design/abc123/MeinDesign?node-id=1-2"

Claude Code liest den Node aus, analysiert Farben, Fonts, Spacing und generiert den passenden HTML/CSS-Code.

2. Code-to-Design (Figma Capture)

Umgekehrt kann Claude Code auch HTML-Seiten zurück nach Figma pushen. Das wird z.B. beim Freebie Generator genutzt:

  1. Freebie wird als HTML generiert (595×842px)
  2. Chrome Headless rendert die Seite
  3. Das Ergebnis wird via Plugin API in Figma eingefügt
  4. Gradient-Fills und Variablen werden nachträglich angewendet

3. Design System erstellen

Mit dem /generate-design-system Skill kann Claude Code ein komplettes Design System in Figma aufbauen:

  • 3-Tier Variablen: Primitives → Semantic → Component-Level
  • Light/Dark Modes mit spezifischen Scopes
  • Typography Ramp: Display, H1–H4, Body, Caption, Overline
  • Spacing Scale: 0, 1, 2, 4, 8, 12, 16, 20, 24, 32, 48, 64
  • Komponenten: Buttons, Cards, Inputs mit Varianten

Wichtig: Die Figma API kann nur Cloud-Fonts laden. Lokale Fonts wie Helvetica Now Display funktionieren nicht — verwende stattdessen Google Fonts oder Adobe Fonts die in der Figma Cloud verfügbar sind.

Wichtige Konzepte

Inkrementelles Arbeiten

Der Figma MCP arbeitet inkrementell — komplexe Layouts werden Schritt für Schritt aufgebaut. Jeder Schritt wird validiert bevor der nächste startet. Das verhindert Fehler und macht den Prozess nachvollziehbar.

Auto-Layout

Figma's Auto-Layout ist das zentrale Layout-System. Claude Code nutzt es standardmäßig für alle Container mit strukturell verbundenen Kindern. Das bedeutet: Kein manuelles Positionieren mit x/y-Koordinaten, sondern intelligentes Spacing und Sizing.

Variablen-Hierarchie

Best Practice ist eine 3-stufige Hierarchie:

Ebene Beispiel Zweck
Primitives orange-500, gray-100 Rohe Farbwerte
Semantic bg-primary, text-accent Bedeutung/Rolle
Component button-bg, card-border Komponentenspezifisch

Verbindung einrichten

Der Figma MCP wird über das offizielle Figma Plugin verbunden. Die Authentifizierung läuft über OAuth direkt in Claude Web:

Figma-Account verbinden

Gehe zu Claude Web (claude.ai) und verbinde deinen Figma-Account über die Integrationen-Seite.

Figma-Datei öffnen

Öffne die Figma-Datei, mit der du arbeiten willst, und kopiere die URL.

URL an Claude Code geben

Gib die URL in Claude Code ein mit einer Anweisung wie "Lies dieses Design" oder "Erstelle dort ein neues Frame".

Bekannte Einschränkungen

  • Nur Cloud-Fonts werden unterstützt (keine lokalen Fonts)
  • Maximale Script-Komplexität: ~10 logische Operationen pro Aufruf
  • Seiten müssen einzeln geladen werden (kein Multi-Page in einem Aufruf)
  • figma.notify() funktioniert nicht im MCP-Kontext
