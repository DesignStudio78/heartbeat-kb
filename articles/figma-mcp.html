Figma MCP: Designs lesen, erstellen und bearbeiten

Deep Dive 📖 12 Min. Lesezeit Aktualisiert: Juni 2026

Was ist der Figma MCP?

Der Figma MCP ist die Brücke zwischen Code und Design. Er nutzt die offizielle Figma Plugin API und erlaubt Claude Code, direkt in Figma-Dateien zu arbeiten — Designs auslesen, Nodes erstellen, Komponenten bauen, Variablen setzen.

Figma MCP in Claude Code einrichten

Die Einrichtung passiert komplett im Terminal. Beim ersten Zugriff öffnet sich automatisch die Figma-Anmeldung im Browser.

Voraussetzung: Claude Code muss installiert sein (Setup-Anleitung). Falls Claude Code gerade läuft, zuerst mit Ctrl+C oder /exit beenden.

Schritt 1: Figma MCP hinzufügen

Diesen Befehl im Terminal eingeben:

claude mcp add --transport http --scope user figma https://mcp.figma.com/mcp

Schritt 2: Prüfen

claude mcp list

In der Liste sollte figma mit der URL erscheinen.

Schritt 3: Claude Code starten und Figma autorisieren

claude

Jetzt in Claude Code eine Figma-bezogene Anfrage stellen, z.B.:

Zeig mir die Seiten in meiner Figma-Datei:
https://figma.com/design/deine-file-id/DeineDatei

Was passiert: Beim ersten Mal öffnet sich automatisch ein Browser-Fenster. Dort mit dem Figma Marketing-Account einloggen und den Zugriff bestätigen. Das musst du nur einmal machen.

Was kann der Figma MCP?

Designs auslesen

  • Screenshots: Jeden Node als Bild exportieren
  • Design Context: Farben, Fonts, Spacing aus einem Design extrahieren
  • Metadaten: Komponentenstruktur, Variablen, Hierarchie auslesen

Beispiel: Gib Claude Code einfach eine Figma-URL und sage "Implementiere dieses Design als HTML".

Nodes erstellen & bearbeiten

  • Frames, Text, Formen: Alles programmatisch erstellen
  • Auto-Layouts: Intelligentes Spacing und Sizing
  • Fills, Strokes, Effects: Farben, Rahmen, Schatten setzen
  • Bilder einfügen: Assets hochladen und platzieren

Komponenten bauen

  • Component Sets: Varianten mit Properties erstellen
  • Auto-Layout: Responsive Komponenten die sich anpassen
  • Instanzen: Komponenten wiederverwenden und überschreiben

Variablen & Design Tokens

  • Collections: Variablen-Sammlungen mit Modes (Light/Dark)
  • 3-Tier Hierarchie: Primitives → Semantic → Component-Level
  • Bindings: Variablen an Node-Properties binden

Typische Workflows

1. Design-to-Code

Du gibst Claude Code eine Figma-URL und er extrahiert die Design-Informationen:

Implementiere dieses Design aus Figma:
https://figma.com/design/abc123/MeinDesign?node-id=1-2

Claude Code liest den Node aus, analysiert Farben, Fonts, Spacing und generiert den passenden HTML/CSS-Code.

2. Code-to-Design (Figma Capture)

Umgekehrt kann Claude Code auch HTML-Seiten zurück nach Figma pushen:

  1. Freebie/Seite wird als HTML generiert (z.B. 595×842px)
  2. Chrome Headless rendert die Seite
  3. Das Ergebnis wird via Plugin API in Figma eingefügt
  4. Gradient-Fills und Variablen werden nachträglich angewendet

3. Design System erstellen

Mit dem /generate-design-system Skill kann Claude Code ein komplettes Design System in Figma aufbauen:

  • Variablen: 3-Tier Hierarchie (Primitives → Semantic → Component)
  • Light/Dark Modes: Mit spezifischen Scopes
  • Typography: Display, H1–H4, Body, Caption, Overline
  • Spacing: 0, 1, 2, 4, 8, 12, 16, 20, 24, 32, 48, 64
  • Komponenten: Buttons, Cards, Inputs mit Varianten

Wichtige Konzepte

Inkrementelles Arbeiten

Der Figma MCP arbeitet Schritt für Schritt — komplexe Layouts werden inkrementell aufgebaut, jeder Schritt wird validiert. Das verhindert Fehler bei großen Designs.

Variablen-Hierarchie

Ebene Beispiel Zweck
Primitives orange-500, gray-100 Rohe Farbwerte
Semantic bg-primary, text-accent Bedeutung/Rolle
Component button-bg, card-border Komponentenspezifisch

Bekannte Einschränkungen

  • Nur Cloud-Fonts: Lokale Fonts wie Helvetica Now Display funktionieren nicht über die API. Nur Google Fonts und Adobe Fonts die in der Figma Cloud verfügbar sind.
  • Max. 10 Operationen pro Aufruf: Komplexe Layouts werden in mehrere Schritte aufgeteilt.
  • Seiten einzeln laden: Jede Seite muss separat gewechselt werden.
